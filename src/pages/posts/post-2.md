# 博客搭建过程回顾
## 环境搭建
### 1.下载Node.js/npm
Node.js 相当于CPython之于Python 是Javascript的解释器
npm 相当于uv之于Python 是Node.js的包管理器

## 创建Astro项目
### 1.创建Astro项目
```npm create astro@latest```
类似于`uv init`会自动帮你搭建项目框架
### 2.启动开发服务
```npm run dev```
类似于`flask --app main run`启动服务器
